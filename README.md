# Lovewise 假数据看板 v1

北极星：每周核心使用用户数。本原型用于审阅指标层级、口径和下钻交互。

## 打开

在本目录运行 `python3 -m http.server 4187 --bind 127.0.0.1`，访问 http://127.0.0.1:4187 。无需安装依赖。

## 审阅路径

1. 总览查看北极星 = WAU × 周核心使用率；展开构成。
2. 点击指标名称或数值，查看口径、趋势、设备/新老用户/使用场景分组，以及分子、分母模拟明细。
3. 切换活跃与留存、首次与交付、价值与沉淀、AI与成本、付费与权益。
4. 切换四个模拟场景，观察不同问题如何呈现；可切换日期、设备和导出当前表。

## 数据边界

420个合成账号，90天日期范围，固定随机种子。本地生成并计算，无API、埋点、真实账号或外部数据服务。全局筛选同步作用于数值、趋势和明细。

本版是核心指标交互样稿，未穷举设计稿全部75项指标。反馈为发生期快照，连续活跃展示至少3天占比，未提交分析为周口径，复购展示人数；均标注变体，不能视为正式成熟批次指标。模拟交易仅iOS人民币；未提供结算现金，显示缺失而非0。各模拟场景用于演示，不是因果实验或真实预测。

分组按发生时状态拆分，用户可跨组出现，总体重新去重；不能把所有分组人数简单相加。核心使用的功能人数可重叠，一级比率下的功能人数是诊断项。

## 验证

36组场景/设备/日期组合检查人数分区、北极星恒等关系和比例范围。浏览器检查六主题、四场景、下钻维度、分母明细、Esc关闭、CSV导出和360px窄屏。

布局参考用户指定项目 https://github.com/yisu0830/suekit-virtual-shop 的表格主次思路，代码和视觉独立编写，未复制其代码或资源。

## 日期范围与周期对比

可选择2026-07-24至2026-10-21内任意本期日期，默认与前一等长周期比较，也可自选对比日期。点击应用筛选后，主表、下钻分群和CSV均使用同一周期。对比超出完整样例范围显示不可比；不同天数有提示。人数跨日重新去重，比例用周期分子/分母重算。

7天时显示每周北极星，其他天数显示周期指标。DAU取期末，DAU/MAU取期末及此前30天；D7及累计7天回访按所选首活批次计算，截至期末未满7天的用户不入分母。默认最近7天首活批次均未成熟，留存显示空值。连续两期活跃始终与本期之前的等长周期交集，自选对比不改变该指标定义。

趋势改为本期单日计算，长周期最多14个等距采样点，未成熟留存不会填0。下钻同时展示两期值、变化、比例分母，并可切换两期明细。

## 自动排查建议

顶部最多展示3个待验证的改进方向，支持展开支持证据、交叉证据、判断限制和指标下钻。使用透明规则，无外部AI调用。两期需等长、不重叠且数据完整；两期分母各至少20、下降至少3个百分点才入选。按权益交付、分析交付、使用与付款、反馈排序，同类按下降百分点排序。未达门槛时不凑满3项；门槛是演示规则，不代表统计显著性或完整异常检测。指标工作台默认收起。
